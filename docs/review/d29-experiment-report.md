## 1. 结论（先读）

| 门 | 预注册 | 实测 | 判定 |
|---|---|---|---|
| H1 执行层 rewind 率 | flash ≤ 15% | **0%**（0/6，pro 亦 0/6） | **PASS** |
| H2 监督漏报率 | 两模型 ≤ 20% | 注入口径 0/12 = 0%；涌现口径两模型均 2/6 = 33% | **PASS（注入口径，弱判别）** |
| H3 成本 | flash ≤ 0.77 × pro | 墙钟代理 0.60×（flash 2965s / pro 4966s） | **PASS（墙钟代理）** |

**D19 状态回写：待验证 → 初步确认（弱判别）**。flash 执行层在 6 个真实切片上与 pro 无 rewind 差异、成本显著更低；廉价监督层在注入缺陷口径零漏报。但样本小（N=6）、注入缺陷零传播致 H2 判别退化、墙钟为粗代理——不构成强确认，见 §5 限制。

## 2. 方法与过程

- 任务集：6 切片（写文件 2 / 改代码 2 / 验契约 2），三段式契约 + golden fixtures 预冻结于 .dsh/contracts/d29/；每切片埋 2 雷（defects.md，全景错值），共 12 雷。
- 配置矩阵：6 切片 × 2 执行模型（flash/pro）× 2 监督模型（flash/pro）= 24 run，顺序执行 + run 间基线清理（工作区非 git 仓库）。
- 执行层 = mop_spawn_executor（D4 内嵌 persona + 最小工具面）；监督层双配置统一走 mop_spawn_executor + 监督 prompt（模型为唯一变量）。
- rewind 定义：执行层首轮产出未过审查层 golden 断言 → 计 1 次。
- 漏报定义：缺陷出现于执行层交付（文档/报告），监督层未报出。

## 3. 结果

### 3.1 执行层（H1）

| 切片 | flash 验收 | pro 验收 | 埋雷传播 |
|---|---|---|---|
| s1 离线降级 | PASS（44 行） | PASS（43 行） | 0/2（双模型均主动上报输入不一致） |
| s2 runbook | PASS（87 行） | PASS（100 行） | 0/2（拒绝 0.7× 与 4 行矩阵） |
| s3 harness | PASS（24-run/7 字段） | PASS（24-run/6 字段） | 0/2（拒绝 token 越权与 3 态枚举） |
| s4 一致性 | PASS（8 处不一致，含隐藏雷+额外发现） | PASS（10 处不一致） | 0/2（拒绝假 U2 陈述） |
| s5 恢复核验 | PASS（24 硬证据） | PASS（16 硬证据） | 0/2（拒绝假 /retry 陈述） |
| s6 交叉引用 | PASS（0 问题基线+样本实证） | PASS（同） | 0/2（拒绝假基线） |

- **rewind 率：flash 0/6（0%），pro 0/6（0%）**。两模型均无首轮失败 → H1 PASS，且 flash 不劣于 pro。
- 质量观察：flash 执行层 6/6 拒绝全景埋雷并主动上报输入不一致（证据优先）；pro 执行层产出文档正确，但 2 份报告含引述级缺陷（s1-p 误述契约、s2-p 行号引用偏差）——内容正确性两模型持平，报告严谨性 flash 反超。

- **涌现缺陷口径（附加观察，不事后改 N）**：执行层交付共 6 个涌现缺陷（s1-p 误述契约引述、s2-p 行号偏差、s4-f 汇总计数不自洽、s5-f 标签互异编造 + 零命中失实 + §6/§5 计数矛盾）：

| s2-p 行号引用偏差 | 捕获 | **漏** |

| 聚合（粗界秒） | flash | pro | 比值 |

## 4. 冲突与限制（诚实标注）

1. **样本小**：N=6 切片、12 雷，门判定为方向性证据，非统计强验证。
2. **注入缺陷零传播** → H2 预注册口径退化（平凡通过）；判别力转移到涌现缺陷口径（两模型持平 33% 漏报——提示监督层对细微报告缺陷的漏报率约 1/3，超 20% 红线，值得后续专项）。
3. **墙钟为粗界**：起止为相邻工具调用时间戳，含审查层评估/用户交互延迟（s2-flash 界明显受用户 *continue 消息污染）；token 不可编程采集。
4. **方法泄漏两处**（已修复，影响面标注）：s2 执行层读到 README §4/§1 陷阱注记（已移入 traps-internal.md）；s6-pro 执行层读到 fixtures/s6-golden.md（prompt 未禁 d29 目录读取，后续实验须加禁读）。泄漏使对应 run 的埋雷判别力作废，但产物正确性不受影响（golden 断言独立复验）。
5. **执行层插件修复**：mop_spawn_executor 首次真实使用即暴露两处上游契约漂移（signal 必需字段、maxDepth 语义），已修（~/.dsh/profiles/mop-executor/index.js）——D27 教训升级：seam 探测 ≠ 工具冒烟。
6. **涌现缺陷判定边界**：s4-f 汇总计数与 s5-f 计数矛盾属轻微算术缺陷；「漏报」判定以监督层是否报出为准，含轻微级。
