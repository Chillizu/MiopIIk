# 工作报告与验收输出模板

> 上一级：[communication-protocol](../communication-protocol.md) §2.3–2.5。决策 D9/D17。原则：提示词与报告都保持简洁——字段固定、事实优先、无套话。

## 1. [EXEC] 工作报告（规划层 → 监督层，每周期）

```
[EXEC] 周期 #N <时间戳>
- 目标：本周期对照的规划目标（一句）
- 做了什么：执行动作清单（≤5 条）
- 进展：完成/进行中/阻塞 + 量化证据
- 交付物：路径 + 验证状态（门禁/verification 结果）
- 下一步：下一周期动作与预期（一句）
```

规则：一次消息一个时间戳；大内容走文件引用（`.dsh/progress/current.md` 同步落盘）。

## 2. [CONCERN]（监督层 → 规划层，仅偏离时）

```
[CONCERN] 级别(info/warn/block)｜依据：<协议条目或验收标准>
- 问题：一句
- 证据：文件/行号/日志
- 建议：改哪、怎么改（一句）
```

## 3. P0–P3 验收输出（verification subagent / 监督层独立验收）

```
验收结论：PASS / FAIL(列阻断项)
- P0（阻断）：<文件:行号> <问题> <建议修复>
- P1（影响使用）：…
- P2（质量）：…
- P3（可选）：…
证据等级：URL + 访问日期；与既有文档冲突处显式标注
```

## 4. 里程碑汇报（规划层 → 审查层，上游模型报告模式，D17）

```
# <里程碑> 报告 <时间戳>
## 方法（怎么做的）
## 过程（关键步骤与时间线）
## 结果（量化数据 + 与预注册门对照）
## 证据等级（每条结论：URL/日志/复算脚本 + 日期）
## 冲突标注（与既有文档不一致处）
## 未完成与风险
```
