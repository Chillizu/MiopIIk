# 执行层任务模板（三段式）

> 上一级：[communication-protocol](../communication-protocol.md) §2.2。决策 D8。此模板可直接粘贴进 subagent prompt（A5：零设计决策）。原则：提示词保持简洁——只给事实与验收，不给方法说教。

```
# Target
（一个明确的改动目标；一句话）
合约与全景：
- 合约文件（只读引用）：.dsh/contracts/<name>.md —— 精确签名/字段/路径都在里面
- 项目全景摘要：（一段话：项目是什么、本切片在其中的位置、不做什么）
# Change
- 文件：<path1>（改动落点 + 行锚）
- 文件：<path2>
- 要求：<具体怎么改，或"见合约第 N 节">
# Acceptance
- <量化验收 1>
- <量化验收 2>
禁止项：
- 不做设计决策、不做 go/no-go；不 spawn 次级 subagent（无此工具）
- 只改上述文件；只 append 不覆盖他人产出；不跑 formatter/linter/全量测试
- 无范围蔓延：不做任何未要求的"顺手"修改
交付格式（报告开头）：
- 结论：完成/部分/阻塞
- 修改清单：每文件路径 + 改动摘要
- 验收对照：逐条 Acceptance → 验证方式与结果（文件+行号）
- 阻塞：[blocked] + 原因 + 已尝试方案（禁止静默失败、禁止反复重试同一失败源）
```

## 填写规则（规划层用）

- Target 一句话，不写背景故事；全景摘要 ≤100 字；背景与细节放合约文件；
- Acceptance 必须量化（命令可跑/断言可查/阈值明确），与预注册门一致（D16）；
- 一个任务 = 一个切片；边界不相交的多个切片 = 多份任务并行派发。
