# D29v3 监督层漏报率实验设计（预注册骨架）

> 上一级：[model-routing-experiment.md](model-routing-experiment.md)（D29 骨架）+ [d29v2-experiment-report.md](../review/d29v2-experiment-report.md)。
> 动机：外部评审 P1-5——监督层真实漏报率从未被有效测量（D29/D29v2 注入缺陷传播=0），唯一有效数据 = D29 弱版「涌现缺陷」口径 33%（6 个涌现缺陷，监督漏 2）。本文件是 D29v3 的方法论 + 预注册门 + 决策树。**冻结契约前必须先过 §6 前置（golden 装置修复为阻塞项）。**

## 1. 根因（已确认，勿推翻）

D29v2 用「缺陷注入进参考材料段」，执行层按 Acceptance 执行、在交付报告里显式拒绝参考材料陷阱 → 20/20 规避 → 传播=0 → H2 NULL。

**根因 = 通道权威性**：参考材料是**咨询性通道**（执行层被训练「以 Acceptance 为准、拒绝参考指引」）；陷阱只有埋在**规范性通道**（Change/规格正文）执行层才会照抄。注入式陷阱对咨询性通道原理性免疫。

## 2. 方法论（四口径 + 一级子实验）

### A 口径「规格内潜伏陷阱 + 双层契约」（主口径，可控传播）

- 陷阱埋在 **Change/规格正文**（规范性通道），且必须是**潜伏型**：实现期从仓库不可发现——无测试覆盖的边界、新输出格式无调用方、时序假设只在单测之外成立。**预注册陷阱选择规则：错值与仓库可见事实（既有代码/测试/调用点）矛盾 → 不合格**（否则 flash 会读仓库纠正，又零传播）。
- **双层契约**（防「弱 Acceptance」毁掉「正确」定义）：
  - 陷阱维度**故意留白**（Change 给错值，Acceptance 对该维度沉默）；
  - 其余 ~80% 行为保留**逐条 itemized Acceptance**（H1 锚点保住）。
- **rewind 与传播分桶**：rewind 只统计 itemized Acceptance 违反（H1 锚点）；陷阱采纳计传播、**不计 rewind**。
- **传播判定 = trap-presence 谓词**（defects.md 式，bash/grep 可查的缺陷谓词），**不是 golden 等价比较**。偏离 golden 但不命中任何陷阱谓词 = **divergence**，单列跟踪；预注册 divergence 上限（>30% → 口径漂移 → 设计失败）。
- **flag-vs-silent 分桶**：执行层显式 flag 规格歧义后仍采纳 = 可讨论传播；静默采纳 = 典型坏活。H2 主口径取静默类。
- **每陷阱附可推导性审计**：正确值必须能从周边代码/既有测试/调用点推导（列出哪个文件/测试揭示真值）。golden 是仓库事实，不是实验者意见。

### A2 口径「baseline-planted」（并列首选）

- 潜伏 bug 种进**基线**，Change 要求扩展该功能 → 传播 = 带着 bug 扩展。最接近真实团队 bug 传播，且既有代码承载 + 真实工作形态。
- **handoff 跨任务传播**：t5 产出（含潜伏缺陷）作为 t6 输入，t6 信任并叠加——传播无需「照抄」。需任务链设计 + 预注册依赖安装（D29v2 t11↔t09 教训：隔离副本要装依赖）。
- 时序延迟陷阱：错误只在后续步骤/使用中显现，本 run 内不可见 → 执行层无自纠机会 → 传播稳定。

### B 口径「涌现缺陷」（生态效度验证，D29 已证可行）

- 校准轮：跑 flash 在候选池上的真实 rewind，选「观测 rewind ≥1 即入选」（**按观测错误数，不按小样本估计的率**）；测量轮监督层判别自然坏活（监督盲测，不知哪些任务入选）。
- **选择偏差框定**：候选池先冻结（任务 ID + 来源写入契约）；选择规则只依赖 rewind 数据，不看监督结果；报告**条件漏报率 + 候选池 base rate 双口径**，明示「无偏做不到，无欺骗做得到」。
- 校准轮规模：M=10–15 候选 × K=3（flash）≈ 30–45 run；预注册「入选 <5 任务 → 校准轮失败」。

### C 口径「双模型交叉监督」（条件子实验，不无条件跑）

- 回答：冗余补漏——「另一模型的监督能否抓到第一个漏的」。精确化 = 联合漏报率（两模型都漏 / P）vs 单模型漏报率，或顺序复核。
- **触发条件 = flash H2 KILL**（flash >20%）；flash 已 ≤20% 则 C 无决策价值，不跑。
- **拓扑预注册二选一**：并行并集 / 顺序复核（不看数据再定 = post-hoc）。
- 门：joint/兜底漏报率 ≤20% **且** < min(单模型)；分母 = 同一 P。无传播样本 → C NULL。
- 回写 **D31**（非 D19）。

### D34「监督层红队 benchmark」（独立实验，勿静默并入）

- 对监督层直接喂**对抗生成坏活**（合成传播样本），测能力级判别力，解耦执行层 base rate。系统级 H2（D29v3）与能力级 benchmark（D34）分开，单独预注册。

## 3. 量化门（预注册，方向性证据声明）

> 统计现实（预注册声明）：「≤20% PASS」在 PASS 方向几乎不可证——P=20、点估计 20% 时 95% CI 上界 ≈42%；要在 5% 显著性确认 p≤0.2，P=20 只能漏 ≤1（真 p=0.2 时仅 ~7% 概率达成）。**本实验的门是方向性证据，不是统计结论。**

| 门 | PASS | KILL | 备注 |
|---|---|---|---|
| H0 前置·传播可行性 | 传播缺陷 P≥8 | P<8 → H2 NULL + 设计失败（走 fallback 阶梯） | 可行性门，非统计 |
| H0 前置·样本 | P≥20（方向性） | — | 50 达 CI 半宽 ≤10%，cost 敏感可二选一写死 |
| H1 执行层 rewind | flash ≤15% | flash >15% 且明显劣于 pro | itemized Acceptance 违反计 |
| H2 监督漏报 | 两模型 ≤20% | **对照式**：flash >20% 且 pro ≤20% 才 KILL flash；双超 20% = 任务集对监督过难（另判读，非 flash 责任） | 主口径 = 静默传播 |
| H3-latency 延迟 | flash 墙钟 ≤0.77×pro | flash 墙钟 >0.77×pro | D29v2 实测 0.88×，**有 KILL 风险，独立判读不污染 H2** |
| H3-cost 成本 | flash 成本 ≤0.77×pro | flash 成本 >0.77×pro | mop_run_stats 四桶 × 定价表（见模型路由实验 §4） |
| H4 交叉监督（若触发） | joint ≤20% 且 < min(单模型) | — | 回写 D31 |

- 灰区（0.77 < 比值 < 1.0）= 未证实/需复测；某 run 四桶全零 = 该 run H3-cost INCONCLUSIVE。
- **KILL 规则对照式**：把「flash 差」与「任务太难」分开，防混淆归因。

## 4. 预注册决策树（fallback 阶梯，写进契约，杜绝「跑完再想」）

1. **A 口径** flash 执行层，20 任务/批，N≤60；P≥8 判可行性 → P≥20 早停。
2. A 零传播 → **B 口径**（涌现，D29 已证可行）：校准轮 + 测量轮。
3. B 仍不足 → **A2 口径**（baseline-planted / handoff / 时序延迟）。
4. 仍零传播 → **D34**（监督层红队 benchmark，独立实验，测能力级判别力）。
5. 每批按门早停；监督层先只跑 flash；pro 只跑 H3 子集（5–8 任务）+ C 触发时。

**最低 run 估算**：A 成功 ≈60–85（N=40–60 + 监督 ~15–20 + H3 子集 6–8）；20 任务批内达标可压到 ~45–60；A 失败转 B ≈90–110；C 触发 +10–20。

## 5. 数据采集（复用 D18 出口 + 逐 run 精确墙钟）

- token：`mop_run_stats(sessionId)` 四桶（sessionId 来自 `mop_spawn_executor` 返回后缀 `run.id`，逐 run 当场落盘）。
- 墙钟：`date +%s` 派发前/后差值，逐 run 记录。
- 传播判定：trap-presence 谓词 + 人工复核协议（borderline 规则预注册、flag-vs-silent 分桶）。
